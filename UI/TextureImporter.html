Manual selections override detected maps. For duplicate candidates, choose the correct file here.

PNG maps: up to 4096 x 4096 and 64 MiB each. ZIPs: up to 512 MiB, standard ZIP with stored/Deflate entries. Unsupported files (including displacement) are skipped. Base colour alone is valid.
